# Focus Estimation and Distraction Detection System

A real-time student focus and distraction detection system developed using Computer Vision and Machine Learning techniques. The system analyzes eye movement, facial orientation, posture, and emotions to classify users as focused or distracted during online learning sessions.

---

## 🚀 Features

- Real-time focus detection using webcam
- Eye tracking using Eye Aspect Ratio (EAR)
- Facial orientation and posture analysis
- Emotion and engagement detection
- Multiple ML model implementation
- Live dashboard visualization
- Focus vs Time analysis

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/LalitAditya6525/Focus-Estimation-and-Distraction-Detection-System.git
cd Focus-Estimation-and-Distraction-Detection-System
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux/Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

### Train Models

```bash
python src/train_model.py
```

### Run Focus Detection Server

```bash
python src/focus_server.py
```
